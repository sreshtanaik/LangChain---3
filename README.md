# AI Resume Screening System

## Overview
This project is an AI-powered resume screening system built using LangChain.

## Features
- Skill extraction from resumes
- Matching with job description
- Scoring (0–100)
- Explanation of results

## Tech Stack
- Python
- LangChain
- HuggingFace

## Pipeline
Resume → Extraction → Matching → Scoring → Explanation

## Note
LangSmith tracing was attempted. Due to access limitations, manual tracing was demonstrated.

## How to Run
1. Install dependencies
2. Run main.py
